# 谈参生成器（tancan-generator）

一个给 AI 助手用的技能（Skill）：**告诉它你要写哪位领导的谈参，它就按既定格式，自动产出一份可直接使用的谈参 Word 文档。**

适用于公关/品牌侧的高层拜访谈参、会前准备材料、媒体拜访简报。

## 它做什么

- 输入一个姓名 + 机构/职务，自动判断该用哪套模板
- 联网核实履历、机构情况、近期观点与争议
- 按「先问后写」的方式采集你方与该对象的过往合作信息
- 输出一份结构完整、事实可核实的 .docx 谈参

## 两套模板

| 类型 | 适用对象 | 结构 |
|---|---|---|
| **A 机构型** | 报社社长、总编辑等机构领导 | 机构简介 → 领导简介 → 与我方关系概要 → 建议沟通话题 |
| **B 个人IP型** | 评论员、自媒体头部等个人IP | 客户简介 → 履历 → 客户重要性 → 舆论评价与争议性 → 近半年观点 → 过往合作 → 可沟通方向 |

## 安装

```bash
# 方式一：一键安装
git clone https://github.com/<你的用户名>/tancan-generator.git
cd tancan-generator
bash install.sh

# 方式二：手动安装
# 把整个文件夹放到 ~/.workbuddy/skills/ 下即可
```

安装后重启 WorkBuddy，对话中说「写XX的谈参」就会自动触发。

## 依赖

- 无第三方依赖。技能本身是纯指令文件（Markdown），由 AI 助手读取执行。
- 生成 Word 文档需要 AI 助手环境中有 python-docx（WorkBuddy 托管环境已内置）。

## 使用方式

安装后直接在对话里说：

- "帮我写XX报社张社长的谈参"
- "下周要拜访胡锡进，出一份谈参"
- "写一份XX杂志主编的会前谈参"

AI 会先判断模板类型、向你采集合作信息、联网核实公开信息，然后生成 Word 文档。
