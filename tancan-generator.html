两套模板

按对象类型自动选择

机构领导和个人IP的谈参，结构完全不同。技能会先判断类型，再套用对应的模块组合——不会把党报社长的谈参写成大V的写法。

A 类

机构型

报社社长、总编辑、评论部主任等机构领导
  • 1机构情况简介（定位、矩阵、垂类账号）
  • 2主要领导简介（履历时间线、上任背景）
  • 3与腾讯关系概要（投放、选题报道、联合产品）
  • 4建议沟通话题（3 个可落地方向）
B 类

个人IP型

评论员、自媒体头部等无机构依附的个人IP
  • 1客户简介（平台、粉丝量级、内容风格）
  • 2履历信息（完整时间线与代表作）
  • 3客户重要性 · 舆论评价与争议性
  • 4近半年关注重点与主要观点
  • 5过往合作概要 · 可沟通合作方向

XX财经杂志社总编辑 张三 谈参

机构型 · A 类　|　核实说明附文末
一、机构情况简介

《XX财经》创刊于 1998 年，主管单位为 XX 集团，是财经类月刊，在宏观经济、资本市场、产业政策等领域具有较强的议题设置能力，全网用户约 XX 万。

二、主要领导简介

张三，XX 年履新总编辑，目前系上任初期，履历显示其长期深耕财经媒体一线，后续大概率会推动媒体融合与 AI 技术在内容采编侧的应用。

三、与腾讯关系概要
  • 媒体投放合作：年框约 80 万元，覆盖微信公众号、视频号
  • 重要选题报道：在腾讯数字生态大会等节点给予报道支持
  • 融合创新案例：去年联合推出 AI 专题
四、建议沟通话题
  • ① AI 辅助采编：介绍腾讯混元在媒体内容生产的应用
  • ② 财经主题联合策划：共建年度财经观察报告
  • ③ 视频号数字人资讯：已完成技术能力对接，可快速上线
核心特性

为什么它比手动写更可靠

谈参的价值在于事实准确、结构完整、敢说真话。这几点是它被固化成规则的地方。

核

公开信息全部联网核实

履历、机构情况、近半年观点与争议，一律先搜索核实，文末附来源，核实不到标「待核实」。

填

合作信息清单式采集

不编造金额与案例。先出清单让你填，你说没有合作，它就写「具备重启空间」。

真

争议与敏感信息保留

个人IP的舆论争议、被禁言等如实写进对应模块——这是内部谈参区别于对外提案的价值。

落

合作方向具体到产品

不停留在「加强合作」，每个方向都落到可执行的产品、活动或选题，腾讯做资源提供方。

安装

两种方式，一分钟装好

技能本身是纯 Markdown 指令文件，零第三方依赖。安装后重启 WorkBuddy，对话中说「写XX的谈参」即可触发。

一键安装 手动安装
# 克隆仓库并安装 git clone https://github.com/<你的用户名>/tancan-generator.git cd tancan-generator bash install.sh
# 把整个文件夹放到 skills 目录即可 cp -R tancan-generator ~/.workbuddy/skills/

下次直接说「写XX的谈参」

它会先判断模板类型、向你采集合作信息、联网核实公开信息，然后生成 Word 文档。
